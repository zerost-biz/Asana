# 自分のGoogleアカウントで試す（Google Apps Script + スプレッドシート）

自分のGoogleアカウントだけで、このアプリを Web アプリとして動かし、入力内容をスプレッドシートに保存します。**無料・自分1人で試す用**です。

## しくみ
| もの | 役割 |
| --- | --- |
| `Code.gs` | サーバー側。画面を配信し、データを「Data」シートに保存し、CSVをドライブに保存する |
| `index.html` | 画面そのもの（`npm run build:gas` で作った単一HTML。このリポジトリに入っています） |
| `appsscript.json` | 設定（日本時間・Webアプリは「自分だけ」が使える） |

## 手順（ブラウザだけでできます）
1. [Google スプレッドシート](https://sheets.google.com) で**空のスプレッドシート**を新しく作る（名前は自由。例：`Project Delivery OS`）。
2. メニュー **拡張機能 → Apps Script** を開く。
3. 左の歯車（プロジェクトの設定）で **「appsscript.json」マニフェスト ファイルをエディタで表示する** にチェックを入れる。
4. ファイルを3つ用意する。
   - `コード.gs` の中身を、このフォルダの **`Code.gs`** の内容に置き換える。
   - 「＋」→ **HTML** で `index` という名前のファイルを作り（拡張子は付けない）、このフォルダの **`index.html`** の内容を全部貼り付ける（約700KBあるので、貼り付けに少し時間がかかります）。
   - `appsscript.json` の中身を、このフォルダの **`appsscript.json`** の内容に置き換える。
5. 右上 **デプロイ → 新しいデプロイ** → 種類の歯車で **ウェブアプリ** を選ぶ。
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**自分のみ**
   - **デプロイ** を押し、最初の1回は「アクセスを承認」（スプレッドシートとドライブの利用許可）を行う。
     「このアプリは確認されていません」と出たら、**詳細 → （プロジェクト名）に移動** を選びます（自分で作ったスクリプトのためです）。
6. 表示された **ウェブアプリのURL** を開く。ブックマークしておくと便利です。

初回に開くとデモデータが入り、以後の操作は自動でスプレッドシートの「Data」シートに保存されます。別の端末で同じURLを開いても同じ内容になります。

## 使い方のメモ
- **CSV**：レポート画面の「CSVで出力」は、ブラウザのダウンロードではなく、**マイドライブの「Project Delivery OS」フォルダ**に保存されます。保存後のメッセージの「開く」から開けます。
- **データを見たい**：スプレッドシートのメニュー **Project Delivery OS → 内容をシートに書き出す（閲覧専用）** で、各表（プロジェクト・作業・作業時間・社内オーダー…）が「表_◯◯」シートに書き出されます。ここを編集しても画面には反映されません。
- **初期データに戻す**：アプリの 管理 → データ → 初期化。
- **画面を更新したとき**：新しい `index.html` を貼り直し、**デプロイ → デプロイを管理 → 編集（鉛筆）→ バージョン：新バージョン** で再デプロイします（URLは変わりません）。

## 画面を作り直すには（開発者向け）
```bash
npm run build:gas   # 単一HTMLをビルドして gas/index.html を更新
```
[clasp](https://github.com/google/clasp) を使うと貼り付けなしで反映できます（`gas` フォルダで `clasp create --type sheets` → `clasp push`）。

## トライアルの制限
- **自分1人用**です。複数人が同時に編集すると、後から保存した内容が勝ちます（他の人の変更は再読み込みするまで反映されません）。
- 画面上の「操作ユーザー」切替は権限の確認用で、**本物のログインではありません**。URLを知っていても、Webアプリを「自分のみ」にしていれば他の人は開けません。
- データ全体をまとめて読み書きします（保存に1秒前後）。数千行を超えると重くなります。
- 本格運用では、表ごとのシート保存・差分更新・ログインしたメールアドレスによる権限確認が必要です（ルートの README「GAS へ移植する際のポイント」参照）。
